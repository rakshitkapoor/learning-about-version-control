# learning-about-version-control
Author: Rakshit Kapoor

Solving merge conflicts takes conscious effort, but I can do it!

### what I like about version control
- I really like how version control allows everyone to collaborate through separate branches while keeping a stable main branch. Having our code safely backed up in the cloud is another huge advantage, ensuring our work isn't lost if something happens to our local machines. I also love how this collaborative approach has helped open-source communities grow and flourish.

### what I find frustrating about version control
- What I find frustrating is dealing with merge conflicts, especially when multiple people are working on the same files. Keeping branches in sync and resolving conflicts can sometimes become time-consuming, particularly when everyone has made changes independently. It can also be easy to lose track of changes if commits and communication aren't handled properly.
